## Your course repository on GitHub
Within this course, you will submit your individual solutions to one personal GitHub-hosted learning log created through Classroom 50. You will use this course repository for all assignments, even if you have other GitHub repositories.

Find both invitation links in ILIAS and follow the two [Classroom 50 setup steps](/moer-mpg-upscaling/unit00/unit00-01_learning_environment.html#classroom-50-and-github). Your instructors must add you to the course roster before the links will let you join. Accept the invitation to **GeoMOER-Students-Space**, then accept the course repository assignment. Classroom 50 provides the repository link under **My submission**.
Your course repository will be hosted in GeoMOER-Students-Space on GitHub.
The submissions generally encompass R or R Markdown AND the compiled html files.
For details, see the [Deliverables](/moer-mpg-upscaling/unit00/unit00-02_deliverables.html){:target="_blank"} section.



If you do not yet have a GitHub account, create one before following the setup steps above.
Keep the same learning log repository until the end of the course.
Please also add your full name or your student account name to your GitHub profile.
{: .notice--info}

Aside from submitting assignments, you should use your repository for everything related to this course which is a potential subject to version control, team collaboration and issue tracking.
{: .notice--success}
