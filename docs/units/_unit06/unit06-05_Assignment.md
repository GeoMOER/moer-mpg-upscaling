* Extract the AlphaEarth embeddings for all plots and save them as `plot_embeddings_<year>.csv`. Commit your GEE script (copy it into a `.js` file) and your R script to your GitHub classroom repository.
* Include the PCA plot from the exercise in an R Markdown (html) document.
* Write a short reflection (200–300 words) in the same document:
  * How could embeddings help in your own research project?
  * Where could they mislead you? Think about interpretability, bias, and the spatial scale of your plots.
  * Would you use embeddings, classic predictors, or both? Why?
